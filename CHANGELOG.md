# Changelog

## v0.2.0 — European version

- European version (`0004000000030200`, `CTR-P-AKDP`): built and checked against the EUR game code, **not yet played**.
  Same patch as JPN/USA; only the addresses differ.
- JPN and USA patches are unchanged from v0.1.0 (byte for byte).

## v0.1.0 — first test release

- C-Stick / Circle Pad Pro aims through the game's own analog-aim code while the Circle Pad keeps moving Pit.
- Touch Screen still works and takes priority.
- *Invert Vertical* (Reticle/Camera) applies to the C-Stick.
- Japanese version: tested on Azahar with this exact `code.ips` (Land Battle, Air Battle, Circle Pad movement and dash, touch priority, inverting, menus, "Try It!").
- North American version: built and checked against the USA game code, **not yet played**.
- European version: not yet supported.
- Note added: replacing another mod's `code.ips` with this one can crash the game — merge them instead.
